# 第一部分 非连续性文本阅读大全

## 一、什么是非连续性文本？

非连续性文本：

不是完整文章，

而是由多个材料组成。

常见形式：

- 图表
- 数据
- 表格
- 海报
- 广告
- 新闻材料
- 调查报告
- 说明资料
- 漫画
